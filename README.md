# Telegram Beauty Booking Bot

Телеграм-бот для записи к специалистам индустрии красоты. Поддерживает онлайн-запись, управление расписанием, интеграцию с Google Calendar, приём предоплат и аналитику для мастеров.

## Возможности

- выбор услуги, мастера, даты и времени прямо в чате;
- автоматическая проверка доступных слотов и учёт акций/скидок;
- подтверждение, отмена и напоминания о записи (за сутки и за час);
- синхронизация с Google Calendar мастера (по желанию);
- генерация ссылки на оплату через ЮKassa (эмуляция);
- сбор отзывов по завершённым визитам;
- рассылка текущих акций клиентам;
- аналитика и подписки для мастеров.

## Быстрый запуск

1. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. Создайте файл `.env` с переменными окружения:

   ```env
   BOT_TOKEN=<токен вашего бота>
   DATABASE_URL=sqlite+aiosqlite:///./bot.db  # при необходимости используйте PostgreSQL/MySQL
   GOOGLE_APPLICATION_CREDENTIALS=/path/to/credentials.json  # опционально
   YOOKASSA_SHOP_ID=<идентификатор магазина>
   YOOKASSA_API_KEY=<секретный ключ>
   ```

3. Запустите бота:

   ```bash
   python -m bot.main
   ```

При первом запуске база автоматически наполнится тестовыми услугами, мастерами и акцией. Все ключевые сервисы собраны в папке `bot/`.

## Структура проекта

```
bot/
├── analytics.py          # сервис аналитики по клиентам и выручке
├── config.py             # загрузка конфигурации из переменных окружения
├── database.py           # настройка асинхронного SQLAlchemy
├── google_calendar.py    # интеграция с Google Calendar
├── handlers/             # aiogram-обработчики диалогов
├── main.py               # точка входа
├── notifications.py      # планировщик уведомлений (APScheduler)
├── payments.py           # абстракция платежей (ЮKassa)
├── promotions.py         # работа с акциями
├── seed.py               # заполнение справочников базовыми данными
├── services/             # бизнес-логика (записи, отзывы и т.д.)
└── subscriptions.py      # управление подписками для мастеров
```

## Подписки для мастеров

Файл `bot/subscriptions.py` содержит сервис, позволяющий продавать доступ к боту по подписной модели. Мастеру можно автоматически продлевать подписку после успешной оплаты.

## Планировщик уведомлений

Напоминания организованы через `APScheduler`. Если требуется интеграция с внешними CRM, адаптируйте колбэк `NotificationCallbacks.send_message`.

## Интеграция с Google Calendar

Для синхронизации создайте сервисный аккаунт Google и выдайте ему права на календарь мастера. Путь к JSON-файлу с ключами укажите в переменной `GOOGLE_APPLICATION_CREDENTIALS`.

## Оплата

В `bot/payments.py` находится заглушка под ЮKassa. Подключите официальный SDK, чтобы переводить платежи в рабочий режим.
